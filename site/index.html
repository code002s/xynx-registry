Features

Free

No payment

Your name.xynx.surf costs nothing. No card, no trial, no account on this site.

Git

Everything in a pull request

One JSON file per subdomain. A bot checks it, a maintainer merges it.

DNS

Automatic records

After merge, A, AAAA, CNAME and TXT records are created in Cloudflare within minutes.

How it works

Step 1

Pick a name

Type it above. If it is free, the button turns on.

Step 2

Send the file

GitHub forks the repo and opens domains/name.json with a template. Fill in your login and target.

Step 3

Wait for merge

The check runs on its own. After merge your subdomain starts resolving.

Rules

  • Name: 2 to 30 characters, a-z, 0-9 and a hyphen, not at the start or end.
  • Up to 3 subdomains per person, up to 10 records per subdomain.
  • The owner login in the file must match the pull request author.
  • CNAME cannot sit next to A or AAAA on the same name.
  • No phishing, malware, spam, illegal content or impersonation. Such subdomains are removed without warning.
  • A subdomain pointing to a missing service for 90+ days can be released.
